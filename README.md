## Тестлэх функц ба төлөөлөх утгууд

Тестлэх функц нь `POST /registrations`. Тохируулгад багшийн өгсөн локал API болон зохиомол оюутны бичлэгүүд ашиглав.

| Сонголт | Төлөөлөх утга |
|---|---|
| Оюутны төлөв | Идэвхтэй, идэвхгүй, байхгүй |
| Үзсэн хичээл | Бүрэн, хэсэгчлэн, хоосон |
| Хичээлийн код | Байгаа, байхгүй, JSON-д орхисон |
| Урьдач нөхцөл | Бүгд хангагдсан, зарим нь дутуу, бүгд дутуу, урьдач нөхцөлгүй |
| Биеийн формат | Зөв JSON, эвдэрсэн JSON |

## Ажиллуулах ба үр дүн

Эхний терминалд `node server.js` ажиллуулна. Хоёр дахь терминалд:

```powershell
newman run lab05-collection.json
newman run lab05-collection-fail.json
```

DOWN туршилтад эхний терминалын серверийг зогсоогоод зөв collection-ийг дахин ажиллуулна.

| Гүйлт | Assertions | Унасан | Exit code |
|---|---:|---:|---:|
| [PASS](results/newman-pass.txt) | 56 | 0 | 0 |
| [FAIL](results/newman-fail.txt) | 56 | 1 | 1 |
| [DOWN](results/newman-down.txt) | 56 | 56 | 1 |

FAIL хувилбар анхны бүртгэлийн HTTP 201 хариунд зориуд 200 гэж хүлээсэн. DOWN хувилбарт `ECONNREFUSED` гарсан нь HTTP хариу ирэхээс өмнө холболт тасарсныг заана. FAIL үед HTTP хариу ирж, хүлээгдсэн статустай зөрсөн.

## Дүгнэлт

Тестийн дизайнд сонголтуудыг тодорхойлж, ангилал бүрд төлөөлөх утга сонгов. Хамгийн их бодол шаардсан алхам нь эдгээр утгаас давхардал багатай спецификаци гаргах байв. Оюутан байхгүй үед үзсэн хичээлийн жагсаалтыг түүнд оноох боломжгүй тул энэ хоёр утгыг нэг хослолд ашиглаагүй. Оюутан болон хичээл зэрэг байхгүй үед API эхлээд оюутны алдааг буцаадгийг тогтоов. Дутуу урьдач нөхцөлтэй тестүүд кодоос гадна дутуу хичээлүүдийн жагсаалтыг шалгасан. Кейс бүр өөрийн бичлэгийг бэлдэж, амжилттай бүртгэлийн дугаарыг тогтмол утгаар шалгаагүй. Үндсэн гүйлт хамарсан тохиолдлуудад API-ийн согог илрүүлээгүй. Зориудын буруу шалгалт Newman-ыг 1 кодоор зогсоосон. Сервер унтарсан гүйлтийн холболтын алдаа нь HTTP хариунд хийсэн шалгалтын алдаанаас ялгаатай байв.
